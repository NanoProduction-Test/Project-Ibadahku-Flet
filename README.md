🕌 IbadahKu
Pendamping ibadah harianmu — jadwal sholat otomatis, checklist ibadah, tasbih digital, doa harian, dan arah kiblat dalam satu aplikasi.

Dibuat dengan Python + Flet. Tersedia untuk Android (APK) dan desktop.

✨ Apa saja isinya?
Fitur	Keterangan
📅 Jadwal sholat otomatis	Terpasang sendiri sesuai kota pilihanmu (data resmi Kemenag RI via AlAdhan), lengkap dengan hitungan mundur menuju waktu sholat berikutnya
☑️ Checklist ibadah harian	Tandai sholat & amalan harianmu — lengkap dengan streak berapa hari berturut-turut kamu konsisten
📋 Kegiatan pribadi	Catat rutinitasmu (ngaji, belajar, olahraga) — bisa diatur per hari, ditandai selesai, diedit, dan dihapus
⏱️ Timer fokus ibadah	Mode pomodoro untuk tilawah, hafalan, atau dzikir khusyuk
📿 Tasbih digital	Tap untuk berdzikir — cincin 33 butir menyala mengelilingi hitungan, bisa ganti dzikir & target
📖 Doa harian	24+ doa pilihan dengan teks Arab, latin, dan artinya — ada pencarian & favorit
🧭 Arah kiblat	Menunjukkan arah Ka'bah dari kotamu, lengkap dengan kompas
📊 Statistik 7 hari & pencapaian	Rekam ibadahmu dan buka lencana pencapaian 🏆
🌙 Mode gelap & 5 warna tema	Sesuaikan tampilan sesuai seleramu
📱 Cara Memasang (untuk pengguna HP)
Download file IbadahKu.apk dari folder rilis / tautan yang dibagikan
Buka file tersebut di HP (biasanya lewat folder Download)
Saat muncul peringatan "sumber tidak dikenal" → pilih Settings → Izinkan (normal, karena aplikasi ini tidak dari Play Store)
Tekan Install → selesai! IbadahKu siap dipakai 🎉
💡 Butuh internet hanya saat pertama kali mengambil jadwal sholat per hari. Setelah itu jadwal tersimpan dan tetap bisa dilihat offline.

🚀 Panduan Singkat Pemakaian
Hari pertama pakai (±2 menit):

Buka tab Atur → pilih kotamu → jadwal sholat langsung menyesuaikan
Selesai! Kembali ke Beranda
Kegiatan harianmu:

Beranda → lihat jadwal sholat hari ini + ayat pilihan + checklist ibadah. Centang tiap selesai
Kegiatan → tekan + Tambah untuk rutinitas baru. Ketuk kartu untuk mengedit
Fokus → pilih durasi → Mulai → beribadah tanpa distraksi
Tasbih → tap tombol besar (atau cincinnya) tiap dzikir
Atur → mode gelap, warna tema, kota, doa harian, kiblat, statistik, pencapaian
❓ Pertanyaan yang Sering Diajukan
Kenapa jadwal sholatnya tidak muncul?Pastikan internet aktif saat pertama kali membuka aplikasi setiap harinya. Setelah jadwal terunduh, ia tersimpan untuk hari itu.

Apakah data saya hilang kalau aplikasi ditutup?Tidak. Semua checklist, kegiatan, hitungan tasbih, dan pengaturan tersimpan permanen di perangkatmu.

Jadwalnya akurat?Ya — dihitung berdasarkan metode resmi Kementerian Agama RI melalui layanan AlAdhan, sesuai koordinat kota pilihanmu.

Apakah gratis dan bebas iklan?100% gratis, tanpa iklan, tanpa akun, tanpa pelacakan. Data kamu tidak pernah dikirim ke mana pun.
